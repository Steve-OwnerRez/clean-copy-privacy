Clean Copy Privacy Policy

Effective and last updated: September 4, 2026

Summary: Clean Copy processes content only in the user's browser after the user invokes the extension. It does not send page content or copied data to the developer or any external service.

1. About Clean Copy

Clean Copy is a Chrome extension that helps users extract and format useful content from the active webpage for copying to the clipboard. It supports structured copying from selected applications and provides general clean-copy and area-selection tools.

2. Information the extension may process

Depending on the page the user chooses to copy, Clean Copy may temporarily process the following categories of information:

  • Personally identifiable information, such as names, email addresses, telephone numbers, postal addresses, usernames, account numbers, ticket numbers, and other identifiers.
  • Financial and payment information, such as transaction amounts, booking totals, balances, and payment-related fields displayed on a page.
  • Authentication information, if credentials, access-token fields, or similar information are visibly present in content the user chooses to copy.
  • Personal communications, including support tickets, emails, chat messages, issue discussions, comments, and internal notes.
  • Location information, such as postal addresses, IP addresses, latitude, or longitude displayed on a page.
  • Web browsing information limited to the active page the user invokes Clean Copy on, including its URL, page title, and visible content. Clean Copy does not collect or maintain a history of pages the user visits.
  • Website content, including visible text, tables, links, labels, metadata, and other content selected for copying.

Clean Copy does not intentionally collect health information or monitor user activity such as browsing behavior, keystrokes, mouse movements, or scrolling.

3. How information is used

Information is processed solely to provide the user-requested copying and formatting features. The extension may expand collapsed page sections, remove interface clutter, organize content into readable text or Markdown, and place the result on the user's clipboard.

Clean Copy does not use information for advertising, profiling, analytics, creditworthiness, lending, or any purpose unrelated to its user-facing copying functionality.

4. Local processing and retention

Page content is processed locally in the user's browser. Clean Copy does not transmit copied page content to the developer or to an external server, and it does not retain that content after the copy operation.

The resulting content is placed on the system clipboard. The user controls where it is subsequently pasted or shared. Clipboard retention is controlled by the user's operating system and other software, not by Clean Copy.

5. Locally stored preferences

Clean Copy uses Chrome's local extension storage to remember user-selected preferences, such as whether links, internal notes, or system notes should be included. These preferences do not contain copied page content and are not transmitted to the developer.

6. Sharing and sale of information

Clean Copy does not sell, rent, disclose, or transfer user data to the developer, advertisers, data brokers, analytics services, or other third parties. The user may independently choose to paste clipboard content into another application or service; that action is controlled by the user and is subject to the privacy practices of the destination service.

7. Permissions

  • activeTab: provides temporary access to the active page only after the user invokes the extension.
  • scripting: allows the bundled Clean Copy code to inspect and format content on that active page.
  • storage: stores the user's extension preferences locally.

Clean Copy does not request persistent access to every website, execute remotely hosted code, or include advertising and tracking technology.

8. Security and responsible use

Users should review copied content before sharing it and follow their organization's policies for customer information, confidential communications, credentials, financial information, and audit data. Users should paste sensitive content only into approved systems.

9. Limited Use compliance

Clean Copy's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only as necessary to provide the extension's disclosed, user-facing copying functionality.

10. Changes to this policy

This policy may be updated when Clean Copy's functionality or legal obligations change. The effective date at the top of this page will be revised when changes are published.
